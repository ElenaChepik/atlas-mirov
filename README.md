# Атлас миров

Интерактивный конструктор планет для детей 10–12 лет. Ребёнок выбирает рельеф, воду, климат, атмосферу, формы жизни, разумных жителей, технологии и общество. Приложение сразу показывает планету, рассчитывает её пригодность для жизни и формирует паспорт мира.

## Возможности

- создание планеты из 9 групп элементов;
- живой предпросмотр и показатели устойчивости;
- объяснения причин и следствий простым языком;
- готовые примеры миров;
- случайная генерация;
- сохранение проекта в браузере;
- печать паспорта планеты;
- скачивание автономной копии.

## Как открыть локально

Откройте файл `index.html` двойным щелчком. Интернет и установка программ не нужны.

## Как опубликовать через GitHub Pages

1. Создайте на GitHub новый публичный репозиторий, например `atlas-mirov`.
2. Откройте репозиторий и выберите **Add file → Upload files**.
3. Загрузите в корень репозитория три файла из этого комплекта: `index.html`, `README.md` и `.nojekyll`.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
7. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
8. Через несколько минут адрес сайта появится в верхней части страницы **Settings → Pages**.

Обычно адрес имеет вид:

`https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/atlas-mirov/`

## Как обновлять сайт

Замените `index.html` в репозитории новой версией и подтвердите изменение кнопкой **Commit changes**. Адрес сайта останется прежним.
